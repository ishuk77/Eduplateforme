# Documentation d’exploitation Eduplateforme

## Objet
Ce module regroupe la documentation d’exploitation et d’usage d’Eduplateforme, plateforme éducative multi-tenant destinée aux établissements, enseignants, élèves, parents et équipes d’administration centrale.

> **Note**
> Cette documentation décrit la cible d’exploitation recommandée. Certains points peuvent dépendre de modules encore en cours d’implémentation, d’intégrations externes ou de décisions d’architecture à finaliser.

## Principes de rédaction
- privilégier des procédures simples, traçables et versionnées dans Git ;
- éviter les détails techniques non garantis par l’état réel du code ;
- expliciter les dépendances vis-à-vis de modules, d’intégrations ou de workflows à finaliser ;
- maintenir la cohérence entre exploitation, sécurité, finance, discipline, communication et audit.
