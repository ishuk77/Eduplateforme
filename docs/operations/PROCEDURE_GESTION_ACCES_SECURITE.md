# Procédure de gestion des accès et de la sécurité

## 1. Création et suppression des comptes
- créer les comptes sur demande autorisée ;
- vérifier l’identité et le rôle attendu ;
- désactiver sans délai les comptes devenus inutiles ;
- conserver une trace des validations.

## 2. Gestion des rôles et permissions
- attribuer uniquement les droits nécessaires ;
- distinguer clairement administration plateforme, établissement, pédagogie, finance et support ;
- revoir toute exception ou élévation temporaire ;
- documenter les accès à privilèges élevés.

## 3. Révision périodique des accès
- planifier des revues régulières ;
- confirmer les droits des comptes dormants ou sensibles ;
- contrôler les comptes techniques et de support ;
- exiger une remédiation rapide en cas d’écart.

## 4. Gestion des comptes compromis
1. suspendre ou réinitialiser l’accès ;
2. qualifier le périmètre exposé ;
3. notifier les responsables appropriés ;
4. revoir les journaux et actions récentes ;
5. restaurer l’accès après sécurisation.

## 5. Rotation des secrets
- inventorier les secrets critiques ;
- définir une fréquence de rotation ;
- limiter leur diffusion ;
- remplacer immédiatement tout secret suspecté compromis ;
- tester les dépendances après rotation.

## 6. Journalisation et audit sécurité
- journaliser les authentifications, changements de rôles, accès sensibles et exports ;
- protéger les journaux contre l’altération ;
- surveiller les anomalies ;
- conserver les éléments nécessaires aux audits et investigations.

## 7. Protection des données d’enfants
- appliquer une confidentialité renforcée ;
- limiter l’accès aux seules personnes habilitées ;
- encadrer strictement les exports et partages ;
- minimiser les données collectées et diffusées ;
- appliquer les exigences légales locales en matière de données personnelles.
