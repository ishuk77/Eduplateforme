# Guide parent

## 1. Connexion au portail parent
- se connecter avec les identifiants reçus ;
- changer son mot de passe selon les consignes reçues ;
- contacter l’établissement en cas de difficulté d’accès.

## 2. Consultation des enfants rattachés
- vérifier que tous les enfants attendus apparaissent ;
- signaler immédiatement toute erreur de rattachement.

## 3. Consultation des notes, absences, retards, devoirs et bulletins
Le portail parent permet de suivre :
- les résultats scolaires ;
- les absences et retards ;
- les devoirs à venir ;
- les bulletins et documents publiés.

## 4. Paiements et frais scolaires
- consulter les frais dus et les échéances ;
- suivre les paiements réalisés ;
- conserver les justificatifs nécessaires ;
- contacter l’établissement en cas d’écart constaté.

## 5. Messagerie et notifications
- lire régulièrement les annonces et messages ;
- utiliser la messagerie avec courtoisie ;
- éviter le partage d’informations sensibles hors besoin scolaire.

## 6. Bonnes pratiques de suivi parental
- consulter régulièrement les informations de chaque enfant ;
- encourager le respect des échéances ;
- maintenir à jour les coordonnées de contact ;
- signaler rapidement toute anomalie liée aux données ou accès.
