# Guide administrateur établissement

## 1. Création et paramétrage d’un établissement
- renseigner l’identité de l’établissement ;
- définir le calendrier scolaire de référence ;
- paramétrer les responsables, contacts et règles internes ;
- contrôler la cohérence des données avant ouverture aux utilisateurs.

> **Note**
> Certaines options peuvent dépendre de modules encore en cours d’implémentation ; elles doivent alors être documentées comme processus cibles ou gérées temporairement par procédure manuelle.

## 2. Gestion de l’année scolaire, des classes et des matières
- créer l’année scolaire et ses périodes ;
- ouvrir les classes et niveaux ;
- rattacher les matières aux classes ;
- affecter les enseignants par matière ;
- vérifier les chevauchements et doublons organisationnels.

## 3. Gestion des enseignants, élèves et parents
- créer ou importer les profils ;
- associer les élèves à leur classe ;
- rattacher les parents ou tuteurs aux enfants ;
- désactiver les comptes inactifs ;
- conserver une piste de validation pour les modifications sensibles.

## 4. Paramétrage de la notation
- définir les barèmes, coefficients et périodes ;
- harmoniser les règles de calcul entre classes ;
- encadrer la publication des notes ;
- formaliser la politique de correction et de rattrapage.

## 5. Paramétrage des présences et retards
- définir les motifs standardisés ;
- organiser le circuit de justification ;
- préciser les seuils d’alerte ;
- suivre les absences répétées et retards récurrents.

## 6. Paramétrage des frais et paiements
- configurer les catégories de frais ;
- définir l’échéancier ;
- suivre les paiements, reliquats et remises autorisées ;
- sécuriser les accès financiers et les rapprochements.

## 7. Gestion des documents et bulletins
- publier les bulletins selon le calendrier validé ;
- déposer uniquement des documents autorisés ;
- appliquer des règles de confidentialité par profil ;
- vérifier la version diffusée avant communication.

## 8. Gestion de la communication école-parent
- utiliser les canaux institutionnels validés ;
- éviter le partage de données sensibles hors périmètre ;
- tracer les annonces générales et messages importants ;
- prévoir une procédure de modération si nécessaire.

## 9. Gestion de la discipline
- enregistrer les incidents de manière factuelle ;
- documenter les mesures prises et les responsables ;
- notifier les familles selon le règlement intérieur ;
- protéger l’accès aux dossiers disciplinaires.

## 10. Checklist de rentrée scolaire
- [ ] année scolaire ouverte ;
- [ ] classes et matières validées ;
- [ ] enseignants affectés ;
- [ ] élèves et parents rattachés ;
- [ ] règles de notation et présence configurées ;
- [ ] frais scolaires publiés ;
- [ ] modèles de communication préparés ;
- [ ] contrôle des accès administratifs effectué.
