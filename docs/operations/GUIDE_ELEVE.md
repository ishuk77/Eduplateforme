# Guide élève

## 1. Connexion au portail élève
- se connecter avec les identifiants personnels ;
- ne pas partager ses accès ;
- signaler à l’établissement tout problème de connexion.

## 2. Consultation des cours, devoirs, emploi du temps, notes et progression
Le portail élève permet de consulter :
- les cours et ressources ;
- les devoirs et dates limites ;
- l’emploi du temps ;
- les notes et observations ;
- la progression scolaire.

## 3. Soumission des devoirs
- respecter les échéances ;
- vérifier le bon document avant envoi ;
- contrôler la confirmation de dépôt si le module est disponible.

## 4. Consultation des documents et messages
- lire régulièrement les messages de l’établissement et des enseignants ;
- consulter les documents publiés dans les espaces autorisés ;
- signaler tout contenu inaccessible ou erroné.

## 5. Bonnes pratiques d’utilisation
- protéger son compte ;
- adopter un comportement respectueux dans les échanges ;
- garder une organisation régulière ;
- demander de l’aide en cas de difficulté technique ou pédagogique.
